# Codex Watch for Mac

The Mac companion for Codex Watch on Apple Watch, by Blue Matters Studio.

[Codex Watch](https://codex-watch.bluematters.studio/) · [Setup and support](https://codex-watch.bluematters.studio/support/) · [Privacy](https://codex-watch.bluematters.studio/privacy/)

Requires an Apple silicon Mac running macOS 26 or later, Codex, and internet access. Keep your Mac awake while using the Watch app.

1. Download the Mac release and unzip it.
2. Move **Codex Watch.app** to **Applications** and open it alongside Codex.
3. Choose **Pair watch**, then connect from Codex Watch on your Apple Watch and compare the verification numbers.

No Cloudflare account or network configuration is needed.
